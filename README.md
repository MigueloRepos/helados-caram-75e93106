# Helados Caram

Construye una app web interactiva mobile-first para Helados Caram fiel a la imagen de referencia visual que adjuntaré en el siguiente mensaje. Estética premium minimalista: fondo crema, naranja Caram, texto carbón, CTAs verdes de WhatsApp, fotos de productos, tarjetas redondeadas y tipografía moderna sin Fredoka. Marca Caram, slogan “La felicidad tiene un sabor”. Incluye Inicio, catálogo, Helados, Dulces, Cake, Brazo de gitano, Mini cake, Marquesitas, Capuchinos, detalle, carrito y envío por WhatsApp. Sabores confirmados: Mantecado, Tiramisú, Fresa, Tres Leches, Moscatel, Limón, Naranja-Piña y Chocolate. No inventes precios, teléfono, sabores extra, ingredientes, horarios ni tarifas. Sin precios reales, muestra “Precio por confirmar en WhatsApp”. Centraliza el teléfono en configuración vacía y solo abre wa.me si se configura. Carrito funcional con cantidades y eliminación; mensaje de WhatsApp preparado con productos y cantidades. No pagos, login ni backend. Replica la composición de la referencia y haz pantallas reales navegables, responsive y accesibles.
